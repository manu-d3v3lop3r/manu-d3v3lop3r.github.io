## Context

The project was developed as a Final Degree Project within a three-person team.

The application was designed to help users plan tourist visits in Madrid.

## Problem

Users needed to be able to select the places they wanted to visit and obtain a route adapted to the available time.

The application also needed to provide additional information during the planning and visiting process.

## Solution

An Android application was developed where users could create a profile and select the places they wanted to visit.

Based on the selected places and the available time, the application generated a tourist route.

Google Maps was used to display the map, search for places and work with routes.

The application also displayed weather information and provided a forecast for up to three days.

## Main features

The application included:

- Profile creation and management.
- Selection of points of interest.
- Route generation in Madrid.
- Map visualization using Google Maps.
- Place search.
- Weather information.
- Completed route management.
- Favorites management.
- Authentication through different options available in Firebase.

## Data and authentication

Firebase was used to store information related to profiles, completed routes, favorites and other application data.

Authentication included different options, including username and password, Google and Facebook through the options available in Firebase.

## My contribution

## Technical challenges

One of the main challenges was integrating Google Maps and working with its API.

It was also necessary to understand and correctly define the application's workflow.

These challenges were addressed through API research, testing and analysis of the expected application behavior.

## Testing

The application was tested both using the Android Studio emulator and on a physical Android device.

## Result

The project was developed as a Final Degree Project and provided practical experience in Android development, API integration, maps, data storage and authentication.
